# Request for contributions

Please contribute to this repository if any of the following is true:

- You have access to *Certamen* questions that aren't yet in this repository and would like to help digitize them
- You have ideas for new scripts or AI skills (or enhancements on existing ones) that would be useful to those digitizing *Certamen* rounds or using those digitzed rounds

## How to contribute

- **Step 1** - Fork this repository.
- **Step 2** - Clone the repository to your local machine.
- **Step 3** - Add the changes to your repository.
- **Step 4** - Create a PULL Request. And that's all.

## Issues

If you want to contribute something but don't know what, feel free to look at the [Issues Tab](https://github.com/NJCL-Certamen/certamen-catalogue/issues) for desired functionalities and assign yourself to one.
